# ⚡ Portfolio Web - Pablo Germán Jiménez (dev.break.Boy.Linkin)

¡Bienvenido al repositorio oficial de mi portfolio web personal! Este proyecto refleja la combinación entre la precisión, disciplina y fluidez del **Breaking** con la creatividad y potencia del **Desarrollo Full-Stack**.

---

## 🤸‍♂️ Sobre el Proyecto

Este portfolio fue construido para showcasear mis proyectos, habilidades técnicas y experiencia profesional. Inspirado en el dinamismo del breaking style (powermoves, ritmo y fluidez), la interfaz integra componentes dinámicos, animaciones e interacciones interactivas para brindar una experiencia de usuario ágil y visualmente atractiva.

> *"Ritmo en la pista, estructura y potencia en el código."*

---

## 🚀 Tecnologías y Herramientas

El proyecto está desarrollado utilizando un stack moderno enfocado en rendimiento y modularidad:

### **Core & Frameworks**
- **[React](https://react.dev/)** (`^19.2.8`) - Librería principal para la construcción de la interfaz de usuario.
- **[Vite](https://vitejs.dev/)** (`^8.2.0`) - Build tool de última generación para un desarrollo rápido y optimizado.
- **[Ionic React](https://ionicframework.com/docs/react)** (`^8.8.16`) - UI Components multiplataforma para navegación y elementos dinámicos.

### **Estilos & UI**
- **[Tailwind CSS](https://tailwindcss.com/)** (`^4.3.3`) + **[PostCSS](https://postcss.org/)** / **[Autoprefixer](https://github.com/postcss/autoprefixer)** - Utility-first CSS framework para un diseño responsive y moderno.
- **[Swiper](https://swiperjs.com/)** (`^14.0.7`) - Carruseles e interacciones táctiles de alta performance.
- **[Ionicons](https://ionic.io/ionicons)** (`^8.1.0`) - Iconografía límpia y vectorial.

### **Enrutamiento**
- **[React Router DOM](https://reactrouter.com/)** (`^5.3.4`) & **[@ionic/react-router](https://ionicframework.com/)** - Gestión de rutas y navegación entre vistas.
